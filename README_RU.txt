СИМУЛЯТОР СОЗДАНИЯ ЧУМЫ — GODOT / ANDROID

Проект сделан без HTML. Добавлены экранные кнопки для движения и действия, а обзор на телефоне
управляется перетаскиванием пальца по правой области экрана.

ЗАПУСК В GODOT
1. Установи Godot Engine 4.3 или новее.
2. Распакуй архив и открой project.godot.
3. Нажми F5 для запуска на компьютере.

КАК СОБРАТЬ APK
1. Установи Android Studio/Android SDK и настрой Android SDK path в Godot:
   Editor → Editor Settings → Export → Android.
2. Установи Export Templates той же версии Godot.
3. Открой Project → Export, выбери Android.
4. Нажми Export Project и укажи build/Chuma3D.apk.
5. Для установки на телефон перенеси APK и разреши установку приложения из выбранного источника.

ПРИМЕЧАНИЕ
В эту среду не установлен Godot Engine и Android SDK, поэтому настоящий APK здесь не скомпилирован.
Архив содержит готовый проект для Android-экспорта, но локальная сборка APK потребует Godot, шаблонов
экспорта и Android SDK. При первом экспорте Godot может попросить настроить SDK и ключ подписи.

УПРАВЛЕНИЕ
ПК: WASD, мышь, E, Esc.
Телефон: экранные стрелки слева, перетаскивание справа для обзора, кнопка «Действие».
Сохранения: три слота в меню, записываются в пользовательские данные Godot.


СБОРКА EXE БЕЗ УСТАНОВКИ GODOT НА ТВОЙ КОМПЬЮТЕР
1. Создай аккаунт на GitHub, если его ещё нет.
2. Создай новый репозиторий на github.com (например, Chuma3D).
3. Загрузи в репозиторий ВСЕ файлы и папки этого проекта, включая скрытую папку .github.
4. Открой вкладку Actions и выбери "Build Windows EXE".
5. Нажми Run workflow и подтверди запуск.
6. Когда сборка завершится зелёной галочкой, открой завершённый запуск workflow.
7. Внизу страницы скачай Artifact "Chuma3D-Windows-EXE" и распакуй его.
8. Внутри будет Chuma3D.exe. Godot на твоём ПК для сборки не нужен.

ВАЖНО: этот проектный архив сам по себе не является EXE. GitHub Actions должен успешно
выполнить сборку. Я не запускал эту облачную сборку и поэтому не могу гарантировать,
что она завершится без ошибок. Если GitHub покажет ошибку, пришли её текст или скриншот.
